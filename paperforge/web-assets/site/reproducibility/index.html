Reproducibility

The publication artifacts, exact computations, and Lean development are separate but synchronized layers. This page gives the shortest supported commands for each layer and records what each command certifies.

Publication build

Clone the repository and check out the immutable manuscript release.

git clone https://github.com/SamPetkov/wow284.git cd wow284 git checkout v2.2.8 bash build.sh

The release records a clean multi-pass LaTeX/BibTeX build, synchronized root and arXiv sources, a deterministic three-file arXiv archive, and a complete SHA-256 ledger. The website copies the already-audited PDF; it does not regenerate or silently alter the canonical manuscript.

Exact computation

The principal release checks can be rerun from the repository root.

python scripts/audit_v22_manuscript.py python scripts/verify_extended.py python scripts/validate_repository.py

Individual theorem-level verifiers are linked inline from the manuscript. Representative examples include:

python scripts/verify_proof_audit_02_two_sided_lp.py python scripts/verify_proof_audit_05_small_moore_punctures.py python scripts/verify_proof_audit_09_jorgensen96.py python scripts/verify_proof_audit_13_hs_robustness.py python scripts/verify_three_to_one_excess_bound.py

Exact means exact

Graph distances are reconstructed by integer breadth-first search. Spectral sign decisions use rational LDLᵀ, exact characteristic polynomials, Sturm sequences, integer matrix identities, or explicitly described finite enumeration. Floating-point values may be used for diagnostics, but not for theorem-level eigenvalue ordering.

Lean 4.31

The repository pins its Lean toolchain and Mathlib manifest. The core graph and LP developments can be checked with:

cd lean lake build Wow284 --wfail lake env lean -DwarningAsError=true Wow284CoreAudit.lean lake build Wow284.LPCeiling --wfail lake env lean -DwarningAsError=true Wow284LPAudit.lean

The non-50 finite certificates have separate build targets:

lake build Wow284Extension lake env lean -DwarningAsError=true Wow284ExtensionAudit.lean lake build Wow284Generated3942 lake env lean -DwarningAsError=true Wow284Generated3942Audit.lean

For a flattened standalone replay:

cd .. python scripts/generate_lean_standalone.py --check cd lean lake env lean -DwarningAsError=true Wow284Standalone.lean

Paperforge website

The interactive HTML is generated from the canonical root main.tex using a pinned Paperforge checkout and PreTeXt. The custom project pages are hand-authored, while paper/ is generated and must not be edited directly.

bash paperforge/scripts/build-local.sh

The assembled site is written to paperforge/output/site/. The GitHub Pages workflow performs the same build, runs the smoke tests, and publishes only on pushes to main.
